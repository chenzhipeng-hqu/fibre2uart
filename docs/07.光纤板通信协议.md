# 通信协议格式

**PC -> MCU / MCU -> PC**

| SOF(1byte)                     | check(1)            |            seq(1)            |  len(1)   | cmd(1)                                                       | portLen(1) | port(0~N)                                    | data(0~N) |
| :----------------------------- | ------------------- | :--------------------------: | :-------: | ------------------------------------------------------------ | ---------- | :------------------------------------------- | :-------: |
| PC->MCU: 0xAA<br>MCU->PC: 0xAB | sum: <br/>seq~dataN | 连续相同的<br />seq只处理1条 | SOF-dataN | 0:none<br>1:msg_uart<br>2:msg_rs485<br>3:msg_rs232<br>4:msg_can<br>0x11~1F:升级指令<br/>0x21-2F: 系统指令<br/>0x31-3F: 端口指令 |            | 1-0x7F:下级端口(考虑外部485)<br/>0:广播<br/> | 详见下表  |

```
单节点指令： cmd>0x10, portLen==0, port0为空
转发指令： cmd>0x10, portLen>0, port0~portN有值
广播指令： cmd>0x10, portLen==1, port0 == 0
转发消息：cmd<0x10, portLen > 0, port0~portN有值
广播消息：cmd<0x10, portLen > 0, port0 == 0 
```



## can消息格式

| can_id(4)(LSB)                                               |  data(0~8)(LSB)  |
| ------------------------------------------------------------ | :--------------: |
| [31]: reserved<br>[30]: 0:数据帧, 1:远程帧<br>[29]: 0:标准帧, 1:扩展帧<br>[28-0]: can_id | 0-8个字节can数据 |



# 指令集

## 升级指令

|   cmd    |   指令说明   |                   备注                   |
| :------: | :----------: | :--------------------------------------: |
| **0x11** |   程序跳转   | 进行在线升级前先发送该指令进入bootloader |
| **0x12** | 获取板卡信息 |                                          |
| **0x13** | 发送升级信息 |                                          |
| **0x14** | 发送升级数据 |                                          |
| **0x15** | 查询升级进度 |                                          |



### 0x11 程序跳转

**PC -> MCU / MCU -> PC **

| cmd(1byte) | port(N) | data0                             |
| :--------: | :-----: | :-------------------------------- |
|  **0x11**  |   ...   | 1: 跳转到bootload<br>2: 跳转到app |

```
注：执行完指令，会自动重启系统，100ms之后再获取板卡信息（0x12），确认是否跳转成功
```

| cmd(1byte) | port(N) |   data0~3 (LSB)    |

| :------: | :-----: | :----------------------------------------------------------- |

### 0x14 发送升级数据

**PC -> MCU **

| cmd(1byte) | port(N) |  data0-1 (LSB)   |  data2~N  |
| :--------: | :-----: | :--------------: | :-------: |
|  **0x14**  |   ...   | 数据包SN:0~65535 | 不超过500 |

**MCU -> PC **

|  cmd(1)  | port(N) |  data0-1 (LSB)   | data2                                                        |
| :------: | :-----: | :--------------: | :----------------------------------------------------------- |
| **0x14** |   ...   | 数据包SN:0~65535 | 0x01: 继续升级<br/>0x02: 升级完成<br/>0x03: 升级失败<br>0x04: 程序未擦除 |

```
注：广播升级间隔50ms发一次，第一包数据SN从1开始发送
```

## 端口指令

### 0x31 端口复位

**PC -> MCU / MCU -> PC**

| cmd(1byte) | port(N) | data0         |
| :--------: | :-----: | :------------ |
|  **0x31**  |   ...   | 端口号<br>1-6 |

### 0x32 端口供电

**PC -> MCU / MCU -> PC**

| cmd(1byte) | port(N) | data0          | data1              |
| :--------: | :-----: | -------------- | :----------------- |
|  **0x32**  |   ...   | 端口号<br/>1-6 | 0: 断电<br>1: 供电 |

### 0x33 端口配置

**PC -> MCU / MCU -> PC**

| cmd(1byte) | port(N) | data0          |  data1-4   | data5                                           | data6                                                        |
| :--------: | :-----: | -------------- | :--------: | :---------------------------------------------- | :----------------------------------------------------------- |
|  **0x33**  |   ...   | 端口号<br/>1-6 | <baudrate> | 0: 无校验 NONE<br>1:奇校验 ODD<br>2:偶校验 EVEN | 0: 0.5个停止位<br>1: 1个停止位<br>2: 1.5个停止位<br>3: 2个停止位 |

```
注: 只支持终端口配置，设置端口为CAN时, data5之后无效
```
